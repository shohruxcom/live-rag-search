# live-rag-search

Real-time RAG (Retrieval-Augmented Generation) search prototype.

## Overview

Experimental system for low-latency retrieval + generation pipelines, with focus on streaming and live updates.

## Goals

- Sub-second retrieval for RAG workloads
- Clean separation of retrieval and generation
- Practical evaluation of latency vs quality trade-offs
